# Lab 3: Graphical Editor

## Additional resources

The `extras/` folder contains:

- **A runnable version of the graphical editor**, which you can use as a reference to see how your implementation should behave. To run it, use:

  `java -jar extras/editor.jar`

- **Geometric formulas and code snippets** to help you determine whether a point lies inside a particular shape.

## Submitting the assignment

Unless otherwise stated, you must submit your work before the next lab session.

To submit your solution, open a terminal in the project root directory and run:

```bash
git add -A
git commit -m "Final submission"
git push
```
